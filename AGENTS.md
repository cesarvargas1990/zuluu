# Acuerdo de trabajo con el usuario

Estas reglas aplican a las tareas de este repositorio y complementan las instrucciones de mayor prioridad.

## Preguntas durante el trabajo

- Al iniciar una tarea, revisa si hay decisiones abiertas que puedan cambiar el alcance, los datos, la experiencia de usuario, los permisos o el despliegue.
- Pregunta pronto cuando una respuesta del usuario pueda mejorar materialmente el resultado. Agrupa preguntas relacionadas y ofrece opciones claras cuando sea útil.
- No inventes preguntas por cumplir una cuota ni repitas algo que el usuario ya respondió. Si no hace falta aclaración, continúa sin preguntar.
- Mientras esperas una respuesta, avanza con las partes independientes. No ejecutes acciones que dependan de una decisión pendiente.
- Si eliges una opción razonable para no bloquear el trabajo, declara el supuesto y cómo puede cambiar el resultado.

## Cierre obligatorio

En toda respuesta final incluye un apartado **Pendiente**. Enumera las decisiones, acciones o verificaciones que siguen abiertas y quién debe resolverlas cuando se sepa.

- Si no queda nada, escribe: **Pendiente: Ninguno.**
- Distingue trabajo terminado de trabajo solo compilado, probado, desplegado o verificado en producción.
- No llames pendiente a una mejora opcional; preséntala como siguiente paso opcional.
- Si una acción no se pudo hacer por permisos, credenciales, acceso o falta de datos, indica qué falta y el motivo concreto.
